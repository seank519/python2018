# CBT 연습 테스트 실행 방법

## 가장 쉬운 방법 (자동 실행 스크립트)
1. 이 폴더에서 아래 명령을 실행합니다.
   ```bash
   python run_quiz.py
   ```
2. 기본 브라우저가 자동으로 열리지 않으면, 출력된 `http://127.0.0.1:8000/index.html` 주소를 복사해 접속하세요.

## 수동으로 실행하는 방법
1. 이 폴더에서 간단한 서버를 띄웁니다.
   ```bash
   python -m http.server 8000
   ```
2. 브라우저로 `http://localhost:8000/index.html` 에 접속합니다.

> 단순히 `index.html` 파일을 더블 클릭해도 열리지만, 위처럼 서버를 띄우면 버튼 동작이 더 확실합니다.
